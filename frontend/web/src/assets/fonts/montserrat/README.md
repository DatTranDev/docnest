# Montserrat interface fonts

Unmodified variable TrueType fonts from Google Fonts, commit `47d54ca1ebb14fd864695f1d39dc734f39017c33`:

- [Normal](https://github.com/google/fonts/blob/47d54ca1ebb14fd864695f1d39dc734f39017c33/ofl/montserrat/Montserrat%5Bwght%5D.ttf)
- [Italic](https://github.com/google/fonts/blob/47d54ca1ebb14fd864695f1d39dc734f39017c33/ofl/montserrat/Montserrat-Italic%5Bwght%5D.ttf)

Both cover weights 100–900 and retain the full upstream glyph set, including Vietnamese. CSS loads these assets locally in both Next and static builds; no runtime font CDN is required. The SIL Open Font License is distributed at `frontend/web/public/fonts/montserrat/OFL.txt` and emitted in the standalone site's `fonts/montserrat/OFL.txt` and third-party notices.
