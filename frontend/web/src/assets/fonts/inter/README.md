# Inter interface fonts

Unmodified variable TrueType fonts from Google Fonts, commit `45e3d5269e4a17d823f6d84470bc084dc5ae46f6`:

- [Normal](https://github.com/google/fonts/blob/45e3d5269e4a17d823f6d84470bc084dc5ae46f6/ofl/inter/Inter%5Bopsz%2Cwght%5D.ttf)
- [Italic](https://github.com/google/fonts/blob/45e3d5269e4a17d823f6d84470bc084dc5ae46f6/ofl/inter/Inter-Italic%5Bopsz%2Cwght%5D.ttf)

Both cover the variable optical-size and weight axes and retain the full upstream glyph set, including Vietnamese. CSS loads these assets locally for product UI in both Next and static builds, followed by Segoe UI and system sans fallbacks. The SIL Open Font License is distributed at `frontend/web/public/fonts/inter/OFL.txt` and emitted in the standalone site's `fonts/inter/OFL.txt` and third-party notices.
