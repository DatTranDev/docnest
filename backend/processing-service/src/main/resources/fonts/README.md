# PDF fonts

Unmodified static Noto Sans, Serif and Sans Mono fonts from
[notofonts/noto-fonts](https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf).
Copyright and redistribution terms are preserved in `OFL.txt` (SIL OFL 1.1).
Regular/bold/italic/bold-italic Sans/Serif and regular/bold Mono are bundled.

PDF exports map Arial/Verdana to Noto Sans, Times New Roman/Georgia to Noto Serif,
and Courier New to Noto Sans Mono. Mono italic is synthesized. This provides
deterministic English/Vietnamese output without host font or network dependencies;
it does not promise identical Microsoft-font metrics or complete emoji coverage.
