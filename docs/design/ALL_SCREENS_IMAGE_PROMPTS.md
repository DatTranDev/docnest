# docsnest: full-screen concept prompts

Built-in imagegen mode. Each board uses the original editor concept as a style reference, not as an edit target. Final images belong in `assets/screens/`. These are proposed UI designs, not screenshots or implemented features.

## Shared prompt prefix

Use case: ui-mockup. Generate a NEW high fidelity product UI concept board for docsnest; attached image is STYLE REFERENCE ONLY, not an edit target. Match its blue folded-document mark, humanist Segoe-like UI typography, white #FFFFFF surfaces, cool #F5F7FB background, ink #202B3A, slate #526174, cobalt #2458D3, 8px controls, subtle borders, quiet shadows. Landscape 1800 by 1200 approximately, crisp legible UI text. No perspective, photographs, device renders, invented dashboards, AI, comments, emojis, subscription benefits, avatar stacks or decorative gradients. Use fictional student-project content only. Put a discreet caption at bottom "docsnest / Concept proposal". Board labels outside app frames distinguish separate states. App interface in English. Relevant selection, button hierarchy and states must be obvious. Avoid excessive tiny text; make requested copy readable. Each screen should feel like the same real product as the reference.

Reference image: `assets/docsnest-editor-concept.png`.
